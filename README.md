# FC풉살 내부매치 드래프트

여자 풋살팀 **FC풉살**의 내부매치 팀을 나누는 드래프트 웹앱입니다.
선수 무기명 투표로 지명 순서를 정하고, 코치끼리만 보는 화면에서 드래프트를 진행한 뒤,
**지명 순번을 지운 채로** 결과를 공개합니다.

### 기술
정적 HTML + Supabase(Postgres). 지명 순번·코치 암호는 RLS로 완전히 차단되어 있고,
모든 쓰기는 서버 함수(SECURITY DEFINER)를 통해서만 이뤄집니다.
